# Internship Management System — Company Application

## Overview

The Company Application enables participating companies to manage internship opportunities, review student applications, and monitor the progress of students completing internships within their organizations.

Access is intended for companies authorized by the faculty, supporting a structured collaboration between academic institutions, students, and employers.

## Features

- **Company Authentication:** Provides login functionality for authorized company accounts.
- **Internship Management:** Supports creating, viewing, updating, and deleting internship listings.
- **Internship Details:** Allows companies to define internship descriptions, required technologies, internship periods, and additional requirements or restrictions.
- **Application Management:** Enables companies to review students who have applied for their internships.
- **CV Review:** Allows companies to view applicants' CVs and download them in PDF format.
- **Application Decisions:** Supports accepting or rejecting student applications.
- **Student Progress Monitoring:** Enables companies to review students' weekly work diaries.
- **Feedback and Evaluation:** Supports providing comments and feedback on students' internship performance.
- **Password Management:** Allows company users to change their account passwords.

## Technology Stack

- Java
- JSP-based web application
- Backend integration: Spring Boot REST API
- Database: Shared system database, accessed through the backend

## Integration

The Company Application communicates with the central Spring Boot backend through RESTful services. Internship listings, student applications, CV information, work diaries, and feedback are managed within the shared system.

## Getting Started

1. Clone the repository.
2. Configure the application server and required dependencies.
3. Configure the backend API connection.
4. Set up the required application properties.
5. Build and deploy the application according to the project's server configuration.

## Project Context

This application is one of four components of an Internship Management System developed as part of an Internet Programming university project at the Faculty of Electrical Engineering, University of Banja Luka.
